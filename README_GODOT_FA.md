# LIFE CITY — Godot 4

این شاخه، نسخهٔ بازسازی‌شدهٔ پروژه برای Godot 4 است. نسخهٔ قبلی Unity در شاخهٔ main دست‌نخورده باقی مانده است.

## وضعیت فعلی
- صحنهٔ سه‌بعدی اولیه و شهر رویه‌ای
- جاده‌ها، ساختمان‌ها و چهار ساختمان خدماتی
- شخصیت قابل حرکت با کیبورد
- دکمه‌های لمسی اولیه برای موبایل
- رندرر Mobile برای سازگاری بهتر با گوشی

## اجرای پروژه
پروژه را با Godot 4.x باز کنید و صحنهٔ اصلی را اجرا کنید.

## نکته
این یک پایهٔ اولیه و قابل توسعه است، نه بازی نهایی. هنوز باید گرافیک، مدل‌ها، انیمیشن، خودرو، NPC، بانک، ذخیره‌سازی و چندنفره پیاده‌سازی و آزمایش شوند.

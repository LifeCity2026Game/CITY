LIFE CITY 3.0 — Unity Android Starter

این یک پروژه شروع واقعی Unity با اسکریپت‌های C# است؛ هنوز بازی کامل و نهایی نیست.

روش اجرا:
1) Unity Hub را نصب کن.
2) از Unity Hub نسخه Unity 2022.3 LTS را نصب کن و ماژول Android Build Support را هم انتخاب کن.
3) پوشه LIFE_CITY_3_0_Unity را در Unity Hub با Add project باز کن.
4) پروژه را باز کن و صبر کن Import تمام شود.
5) از منوی بالا File > Build Settings را باز کن، Android را انتخاب و Switch Platform را بزن.
6) برای اجرای اولیه روی کامپیوتر دکمه Play را بزن. شهر هنگام اجرا به صورت رویه‌ای ساخته می‌شود.
7) برای ساخت APK، در Player Settings شناسه Package Name و تنظیمات Android را تکمیل کن و Build را بزن.

کنترل:
- کامپیوتر: WASD یا کلیدهای جهت‌نما؛ نگه داشتن کلیک چپ و حرکت ماوس برای چرخاندن دوربین.
- اندروید: دکمه‌های لمسی روی صفحه برای حرکت.

محتوا در این پایه:
- شهر سه‌بعدی رویه‌ای، جاده‌ها و ساختمان‌ها
- چند ساختمان خدماتی با فضای داخلی اولیه
- شخصیت بازیکن با تنه، سر، دست و پا
- NPCهای متحرک و کیف پول محلی
- حساب اول با موجودی نامحدود، حساب‌های ۲ تا ۶ صفر
- انتقال و برداشت آزمایشی پول NPC
- پنل‌های اولیه بانک، کمد لباس، خودرو و خرید خانه

محدودیت‌ها:
- این نسخه اسکلت اولیه است، نه نسخه نهایی GTA-مانند.
- خودروها هنوز رانندگی کامل، فیزیک و مدل‌های اختصاصی ندارند.
- سیستم لباس در این پایه فقط منوی نمایشی اولیه است و باید به مدل/متریال واقعی متصل شود.
- بانک مرکزی، وزارت اطلاعات کامل، کشور دوم، آنلاین واقعی، ذخیره‌سازی امن و نقشه گسترده در مراحل بعدی تکمیل می‌شوند.
- پروژه در این محیط با Unity Editor اجرا یا APK ساخته نشده است؛ بعد از باز کردن در Unity باید خطاهای احتمالی را بررسی و رفع کرد.
